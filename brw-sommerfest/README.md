# Sommerfest 2026 – Anmeldung

Eigenständige Anmeldeseite (`index.html`) für das Sommerfest des Boxring
Wetterau 1983 e.V., im Farb-/Font-Schema der Vereinsseite
([boxring-wetterau.de](../boxring-wetterau.de)).

- Reines HTML/CSS/JS, kein Backend.
- Formular öffnet beim Absenden das E-Mail-Programm (`mailto:`) mit den
  eingegebenen Daten als Nachricht – es gibt noch keinen echten Endpunkt.
- Datum, Uhrzeit, Ort und Anmeldeschluss stehen als Platzhalter im Kopf der
  Seite und müssen vor Veröffentlichung final bestätigt werden.
